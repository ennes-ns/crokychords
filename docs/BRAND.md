# Brand: Croky

Croky is the project's mascot, a green-cheeked conure (*Pyrrhura molinae*). Every Croky project
(CrokyCraft, croky-horizon, Croky Chords, …) uses the same mascot and palette. The reference art
is the CrokyCraft server icon (`crokycraft-website/data/server-icon.png`, 64×64 pixel art). The
icons and the README banner in this repo are drawn pixel for pixel from the maintainer's pixel
master of Croky, with the scripts in `tools/brand/`.

## Files (`apps/web/public/brand/`)

All app icons are the pixel Croky from the README banner, generated by `tools/brand/make_icons.py`
from the pixel master in the croky asset repository (`master/croky-32.txt`, `master/croky-16.txt`
and `master/palette.json`; the maintainer pixelled each size by hand, so nothing is resampled).
Every pixel is a whole cell: SVGs use `shape-rendering="crispEdges"`, PNGs are 1:1 or an integer
nearest-neighbour upscale.

| File | Use |
|------|-----|
| `favicon.svg` | The whole bird, 32×32 cells, transparent. Main favicon in `index.html`. |
| `favicon-32.png` | Same, 32×32 px. PNG fallback for browsers without SVG favicons. |
| `favicon-16.png` | The hand-pixelled 16×16 bird. PNG fallback at 16 px. |
| `apple-touch-icon.png` | 180×180, the 32-cell bird at 5× on `#121212` (opaque). iOS home screen. |
| `croky-mark.svg` | Logomark: the 32-cell bird on the dark disc, 8 px per cell (320×320). App toolbar. |

The whole bird was chosen over a head crop: at 32 px both read, but the whole bird keeps the
banner's silhouette (green body, red tail) and has a hand-made 16 px version, which a crop does not.

```bash
M=<croky asset repo>/master
python3 -I tools/brand/make_icons.py $M apps/web/public/brand
```

The earlier traced vector art (`croky-art.svg`, `croky-pixel.svg`, `croky-wordmark.svg`, ~320 KB
each) was removed when the icons moved to the pixel master; `trace_pixel_art.py`,
`compose_silhouette.py` and `trace_lib.py` remain in `tools/brand/` for reference only.
`concept_b.py` and `make_icons.py` share the grid and palette code in `tools/brand/croky_pixels.py`.

### README banner (`docs/readme/`)

`banner.png` (3200×880, 2× of 1600×440, on `#121212`) is rendered from `concept-b.svg`, which is
generated by `tools/brand/concept_b.py`. Everything sits on one grid of 5 px cells: Croky pixel for
pixel (`crispEdges`) from the pixel master in the croky asset repository (`master/croky-64.txt` +
`master/palette.json`, which match the sticker reference: grey hooked beak, white eye ring, red
tail; the asset files themselves are not copied here), perched on four chord blocks I V vi IV in
the editor's degree colours (`hsl(hue 45% 26%)` fill, `hsl(hue 45% 38%)` edge, numerals in
`hsl(hue 30% 85%)`, hues from `DEGREE_HUES` in `apps/web/src/music.ts`), and a hand-drawn bitmap
wordmark (cap height 15 cells, stroke 3) in `#f2e5bc`. No gradients, glow, pills or slogan.

Croky Chords uses the Pyrrhura brand palette below, not the croky UI style (`design-system/STYLE.md`
in the asset repository); CROKY.md says not to mix the two.

```bash
M=<croky asset repo>/master
python3 -I tools/brand/concept_b.py $M/croky-64.txt $M/palette.json docs/readme/concept-b.svg \
  && rsvg-convert -z 2 docs/readme/concept-b.svg -o docs/readme/banner.png
```

## Palette (the "Pyrrhura" palette from `crokycraft-website/www/css/base.css`)

| Token | Hex | Where it comes from / use |
|-------|-----|---------------------------|
| `--py-green` | `#2ecc71` | cheeks and wings; primary accent, "Croky" in the wordmark |
| `--py-red` | `#e74c3c` | tail and lower belly; destructive actions, errors |
| `--py-yellow` | `#f1c40f` | upper belly; highlights, the music-note accent, Play button |
| `--py-blue` | `#3498db` | flight feathers; links, secondary accent, taglines |
| crown | `#3b2a26` | dark brown crown; avoid for UI, art only |
| chest | `#f6ecd6` → `#d8c19c` | scalloped cream chest; light text on dark backgrounds (`#f6ecd6`) |
| `--bg-dark` | `#121212` | background disc and app background |
| outline | `#1a1a1a` | 4–5 px outlines in the art, pixel-art heritage |

Rules of thumb: dark UI by default; green is *the* brand colour, yellow is for the one thing you
want clicked, red only for warnings. Keep outlines thick and shapes chunky (the pixel-art
origin). Text: a heavy geometric sans (Avenir Next / Segoe UI / Inter, weight 800) for the
wordmark, system UI font for the app.

## Anatomy (so edits stay on-model)

Three-quarter view facing right, slightly chubby. Dark brown crown and nape, green cheeks, white
eye ring with a dark eye and highlight, dark hooked beak with a light tip, scalloped cream chest,
yellow→orange→red belly, olive-green wings with darker feather edges, maroon-red tail pointing
down-left, pinkish-brown feet. Thick dark outline. That is Croky; a crocodile is not.
